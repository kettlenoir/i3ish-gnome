    # fedora-setup
    
    Fedora GNOME デスクトップ環境の自動セットアップスクリプトです。  
    10画面固定ワークスペース、キーバインド最適化、画面回転（縦・横切
    り替え）などをターミナルから一発で設定します。
    
    ---
    
    ## クイックスタート（1行で実行）
    
    新規インストールした Fedora
    の端末で以下を実行するだけでセットアップが完了します：
    
    ```bash
    bash <(curl -fsSL
    https://raw.githubusercontent.com/kettlenoir/fedora-setup/main/se
    tup_gnome.sh)
  ※ 実行時に接続されているメインモニター名（DP-
  1等）とスケール値を自動検出し、確認しながら登録します。
  ──────
  ## 主な機能とキーボードショートカット
   ショートカットキー     │ 動作内容
  ────────────────────────┼──────────────────────────────────────────
   Super + Q              │ ウィンドウを閉じる
   Super + F              │ 全画面（フルスクリーン）トグル（F11動作
                          │ ）
   Super + Down           │ ウィンドウ直接切り替え（Alt+Escape
                          │ と併用）
   Super + Shift + S      │ スクリーンショットUIを起動（Windows風キ
                          │ ャプチャ）
   Super + 1 〜 9         │ ワークスペース 1 〜 9 へ直接切り替え
   Super + 0              │ ワークスペース 10 へ直接切り替え
   Super + Shift + 1 〜 9 │ ウィンドウをワークスペース 1 〜 9 へ移動
   Super + Shift + 0      │ ウィンドウをワークスペース 10 へ移動
   Super + Return         │ WezTerm 起動
   Super + Shift + V      │ 画面を縦回転（左90°回転・検出スケール維
                          │ 持）
   Super + Shift + N      │ 画面を横に戻す（通常表示・検出スケール維
                          │ 持）
  ──────
  ## その他の設定内容

  • 10画面固定ワークスペース: アプリの有無に関わらず、常に 10
  個のワークスペースが固定化されます。
  • ドック競合排除: Super + 1〜9
  がドックのアプリ起動と競合しないよう解除済み。
  • ダークテーマ: デスクトップ全体を自動的にダークモード（prefer-
  dark）に設定。
  • 入力切替: Fcitx5 とのキー衝突を防止。
